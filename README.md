# VELORA — Premium 3D E-Commerce Website

> Elevate Your Everyday.

VELORA is a premium-looking 3D e-commerce business website designed with a modern, minimal, and luxury visual style. The project was developed as part of the SafeX Solutions Week 4 internship assignment. It focuses on creating a professional shopping experience with responsive layouts, smooth animations, interactive product features, and a functional contact experience.

## ✨ Features

- Premium luxury-inspired design
- Emerald green, cream, and champagne gold color palette
- Fully responsive design for desktop, tablet, and mobile
- Six complete website pages
- Product browsing and product cards
- Add to Collection / cart functionality
- Shopping cart page
- Curated product collections
- Functional contact form
- Smooth page and hover animations
- CSS-based 3D visual elements
- Interactive navigation
- Clean and reusable React components

## 📄 Pages

| Page | Description |
|------|-------------|
| Home | Premium hero section, brand introduction, and main call-to-action |
| About | VELORA brand story and design philosophy |
| Shop | Product browsing with prices, categories, images, and add-to-cart functionality |
| Collections | Curated product collections presented in a premium layout |
| Contact | Contact information and functional contact form |
| Cart | Displays products added to the shopping cart |

## 🎨 Design System

### Color Palette

- **Deep Emerald Green** — Primary brand color
- **Cream** — Main background color
- **Champagne Gold** — Accent color
- **Dark Emerald** — Secondary dark sections

### Typography

- DM Sans
- Playfair Display

The visual system is designed to create a premium, modern, and elegant e-commerce experience.
